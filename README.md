# Netflix Data Analysis Dashboard

## Project Overview

Analyzed Netflix Movies and TV Shows dataset using Python, Pandas, Matplotlib and Seaborn.

## Tasks Performed

- Data Cleaning
- Movies vs TV Shows Analysis
- Content Added Over Years
- Top Genres
- Top Countries
- Rating Distribution
- Duration Analysis
- Heatmap Visualization

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

Netflix Movies and TV Shows Dataset from Kaggle.
